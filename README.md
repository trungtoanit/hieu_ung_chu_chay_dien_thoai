# Hiệu ứng chữ chạy (mưa số 0/1)

Màn hình đen với mưa số 0101 màu trắng, sau đó từng câu được ghép lại từ các hạt sáng, câu cũ tan ra rồi câu tiếp theo xuất hiện, cuối cùng là trái tim.

## Đổi nội dung
- Sửa mảng `MESSAGES` ở đầu thẻ `<script>` trong `index.html` (dùng `\n` để xuống dòng, `<3` để hiện trái tim), hoặc
- Truyền qua link: `.../?msg=Câu 1|Câu 2|<3`

Trang được host bằng GitHub Pages từ nhánh `main`.
